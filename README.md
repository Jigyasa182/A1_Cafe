# ☕ Cafe Management System

A modern, responsive **full-stack web application** built to digitize and streamline cafe operations.  
This system provides customers with a smooth online ordering experience while giving cafe owners a powerful admin dashboard to manage menus, orders, payments, and receipts efficiently.

Designed as a **production-ready solution** for real-world cafes and food outlets, with scalability and customization in mind.

> ⚠️ Demo access may be restricted or disabled for security purposes.

---

## 🚀 Features

### Customer Experience
- **Dynamic Menu Browsing:** Categorized menu with real-time updates from the database.
- **Cart & Order Placement:** Smooth add-to-cart and checkout flow.
- **QR-Based Menu Access:** Customers can scan a QR code to instantly access the menu.
- **Order Receipts:** Downloadable payment receipt in PDF format.
- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.

### Admin Dashboard
- **Secure Admin Authentication:** JWT-based login and protected routes.
- **Menu Management:** Add, update, or remove menu items anytime.
- **Order Management:** View all customer orders and update order statuses.
- **Invoice Generation:** Download order receipts as PDF files.
- **Demo / Maintenance Mode:** Ability to restrict access when required.
